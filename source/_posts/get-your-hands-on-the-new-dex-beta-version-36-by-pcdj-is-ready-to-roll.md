## Get Your Hands on the New DEX Beta - Version 3.6 by PCDJ Is Ready to Roll!

[![DEX 3.6 DJ Software Beta Download](https://i1.wp.com/pcdj.com/wp-content/uploads/2016/03/downloaddex36beta-coverimage.jpg?resize=530%2C298&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2016/03/downloaddex36beta-coverimage.jpg?fit=530%2C298&ssl=1 "Download DEX 3.6 Beta")

![Small DEX 3 Logo](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/02/DEXlogo-sml.png?fit=45%2C45&ssl=1 "Small DEX 3 Logo")

**A new DEX 3.6 [DJ software](https://tools.techidaily.com/pcdj/products/) beta for MAC and Windows is available for download.** 

**Please note:** This is a [beta version](https://en.wikipedia.org/wiki/Software%5Frelease%5Flife%5Fcycle), so please test thoroughly before using live. You can roll back to the public release by re-installing from the DEX 3 support page [HERE](https://tools.techidaily.com/pcdj/products/)

It was our collective decision to release DEX 3.6 as a public beta today due to the depth and breadth of changes and upgrades. For example, the **new loading engine** included in the 3.6 beta is a total [refactor](https://en.wikipedia.org/wiki/Code%5Frefactoring), and **now supports lesser-used file formats such as Flac HD and certain WMA files**. The loading engine **also fixes ‘error loading file’ issues** with certain audio files that should have worked in previous iterations.

[VIEW LARGER IMAGE ![Link Video To Audio Track in DEX 3.6](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/03/videolink.jpg?fit=300%2C238&ssl=1 "Link Video File To Audio Track DEX 3")](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/03/videolink.jpg?fit=814%2C647&ssl=1)

A new and significantly more exciting feature included in 3.6 is **the ability to link video files to audio files**. You will find **a new tab in DEX 3.6’s options for “Video”** — where you can select a folder of video files (Video files can have audio, or no audio) that will automatically play when only mixing audio and not music videos.

As is always the case with DEX 3 free updates **we’ve also exterminated a few pesky bugs** to ensure further overall stability and improved performance.

_**Important:** Please note that Pulselocker functionality is currently disabled (we’re currently updating DEX 3 with a new Pulselocker SDK)._
